# Data Structures

A collection of data structure implementations and projects written in Java.

## 📋 Overview

This repository contains educational implementations of various data structures and algorithms, including test cases to demonstrate their usage and correctness.

## 📁 Project Structure

| File/Component | Type | Description |
|---|---|---|
| **GCD.java** | Algorithm | Greatest Common Divisor implementation |
| **GCDTest.java** | Test Suite | Comprehensive unit tests for GCD algorithm |

## 🚀 Getting Started

### Prerequisites
- Java 8 or higher
- A Java IDE (IntelliJ IDEA, Eclipse, VS Code) or command-line tools

### Compilation

```bash
javac GCD.java
javac GCDTest.java
```

### Running Tests

```bash
java -cp . GCDTest
```

## 📚 Implementations

### GCD (Greatest Common Divisor)
- **File**: `GCD.java`
- **Purpose**: Calculates the greatest common divisor of two numbers using the Euclidean algorithm
- **Test Suite**: `GCDTest.java` with comprehensive test coverage
